# Fase 5.6 — Cuidados Prolongados

## Cambio incluido
Se agrega **Cuidados Prolongados** como nuevo Tipo de atención en Administración y en el perfil Profesional.

Tipos de visita:
1. Visita Médica
2. Kinesiologia
3. Fonoaudiología / Terapeuta Ocupacional
4. Acompañamiento del adulto mayor
5. Visita TENS
6. Visita Enfermería
7. Visita Cuidador

Por ahora, al seleccionar cualquiera de estos tipos de visita, se muestra el mensaje **“Estamos trabajando en este formulario”** y no se permite guardar una evolución clínica hasta que el formulario correspondiente sea implementado.

## Instalación
No requiere nuevas variables de Vercel ni migraciones SQL de Supabase. Desplegar el proyecto actualizado normalmente.
