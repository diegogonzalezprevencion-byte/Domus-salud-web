# Domus Salud Web

Versión actualizada para GitHub/Vercel.

## Cambios incluidos

- El panel de administrador y el panel profesional se mantienen al 100% de la pantalla.
- Al iniciar sesión se muestra una barra superior compacta con el nombre de la persona y el botón **Cerrar sesión**.
- Se elimina el encabezado visual grande del panel una vez iniciada la sesión.
- En **Administrador → Pacientes**, el botón **Ver ficha clínica** abre directamente el historial imprimible/PDF del paciente.
- Se elimina la visualización extensa de historial dentro de la misma sección de pacientes para simplificar la gestión.
- El botón **Enviar formulario** tiene un color diferenciado.
- El formulario previo visible en **Administrador → Pacientes** ahora refleja la misma estructura que recibe el paciente por enlace.
- Se mantiene la edición de texto introductorio y preguntas complementarias.
- Compatible con computador, tablet y celular.

## Despliegue

Subir el contenido completo del ZIP al repositorio de GitHub conectado a Vercel.

Si ya tienes variables SMTP configuradas en Vercel, no es necesario modificarlas para esta versión.
